# ito - 数字配布ツール

部屋コードで集まり、ホストが開始すると、参加者それぞれに1〜100の重複しない数字を配る静的Webアプリです。お題の表示はありません。個々の数字はSupabaseのサーバー側で管理し、参加者は自分の数字だけ取得できます。

## Supabaseの準備

1. Supabaseでプロジェクトを作成します。
2. Authenticationの設定で匿名サインインを有効にします。
3. SQL Editorで `supabase.sql` の内容を一度実行します。
4. Project SettingsからProject URLと公開用の`anon`キーを確認します。`service_role`キーは使用しないでください。
5. `config.js`の`supabaseUrl`と`supabaseAnonKey`にProject URLと公開用の`anon`キーを設定します。

`anon`キーはブラウザーに配信されます。データ保護はキーを隠すのではなく、SQLで設定したRLSとRPC関数の認可で行います。

## GitHub Pagesで公開

1. このフォルダーをGitHubリポジトリに登録します。
2. GitHubリポジトリの **Settings → Pages** で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/ (root)` に設定します。
3. 公開されたPagesのURLを仲間に共有します。

SupabaseのURLと公開用キーを設定した`config.js`もリポジトリに登録してください。このキーは公開前提の値であり、`service_role`キーやパスワードなどの秘密情報は絶対に設定しないでください。

## 遊び方

1. 名前を入力して部屋を作成し、表示された8桁の部屋コードを共有します。
2. ほかの参加者は名前と8桁のコードを入力して参加します。
3. ホストが「数字を配る」を押すと、参加者に異なる数字が配られます。
4. 各参加者の画面には自分の数字だけが表示されます。

待機中にホームへ戻ると参加登録が解除されます。ホストが戻ると待機中の部屋は削除されます。配布後は再接続できるよう参加登録を保持します。

## 開発時の注意

- ルームと参加者はSupabaseに保存されます。データベースのバックアップや利用上限はSupabaseの設定に従います。
- 部屋コードは8桁の16進数です。参加用コードは招待した人にだけ共有してください。
- 現在の実装は1部屋あたり最大100人です。
